# DeepSeek Harness (pi-ai 1.4.0) request bodies

Generated by pi-ai 1.4.0 `anthropic-messages` buildParams (the exact code DSH uses), captured via `onPayload`
with the DSH kiro model config (`forceAdaptiveThinking: true`, no `sendSessionAffinityHeaders`).
Three consecutive turns of one conversation: no `metadata.user_id`, no session header,
`cache_control` on the system block, the last tool and the last user block. Turn 2 ends with
two consecutive user messages (tool_result, then a timestamp reminder), which is what DSH sends.
The conversation text is placeholder content; the tests only depend on the request shape.
